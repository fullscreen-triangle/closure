# closure / zuerich

A runtime for non-convergent social deliberation, and its formal specification.

The instrument instantiates a class of social fact that neither belief-based
nor preference-based accounts predict: a proposal that is widely judged
feasible, opposed by no one, and never adopted — with no participant
experiencing a decision.

## Layout

```
docs/zuerich-common-closure/     the manuscript (39 pp.) + bibliography
prototype/runtime.py             reference implementation of the runtime
validation/fetch_zurich.py       substrate binding: fetch + normalise OGD Zürich
validation/run_validation.py     24 experiments, each written to falsify
validation/results/*.json        per-experiment records + summary
data/                            normalised substrate (raw/ holds the CSVs)
```

## Reproduce

```bash
python prototype/runtime.py            # 14 invariant self-checks
python validation/fetch_zurich.py      # substrate (cached after first run)
python validation/run_validation.py    # full suite -> validation/results/
cd docs/zuerich-common-closure && latexmk -pdf zuerich-common-closure.tex
```

Per Cor. 11.9 what is reproducible is the *protocol and its provenance*, not
the readings; per Cor. 9.10 repeated sessions need not agree, and their
differences are data.

## What the instrument reports — and refuses to

It reports determinations, classes, and **declines**. It does not report
success, failure, or which action mattered. This is enforced, not advised:

- **No exit code** (Thm 11.5). The runtime's vocabulary is four operations
  and none inspects a value, so no quantity it computes can compare an
  achieved state to an expectation.
- **No attribution** (Thm 12.9, Thm 11.11). Admissibility is a global minimum
  expressed in local terms, so no store of local content expresses it; and
  the terminal state does not determine the trajectory that produced it. No
  refinement of the log closes either gap.
- **No instance-fitted effect sizes** (Thm 12.2). Estimating constituent
  powers from the same observations that determine the measured outcome makes
  prediction and measurement the *same algebraic expression* — `r = 1` on
  every data set, including data generated by a process that violates the
  law. Only the type-averaged test (Thm 12.6) is exposed, together with the
  `eta` diagnostic (Prop. 12.8) that says when even that has no power.

A version of this instrument reporting an effect attribution would be
evidence that the theory it implements is wrong.

## Substrate

Public record of the City of Zürich (`data.stadt-zuerich.ch`), used as a
source of **vocabulary and heterogeneity**, not to reconstruct persons:

- `politik_abstimmungen_seit1933` — 11,406 ballot rows; 2,580 carry
  district-level results; 275 municipal questions on six consistently
  reported units, 2002–2026.
- `bev_bestand_..._od3903` — 408,639 population records by district, origin,
  sex and age, 1993–2025 (452,421 residents in the 2025 cross-section).

Measured floor on this binding: **β = 0.0197** — the two most similar
districts differ by ~2 percentage points on average across the record.

Modules are *patterns*, never persons (Def. 8.1); pruning yields fictional
agents consistent with aggregate statistics (§14).

## Validation

24 experiments, **24/24 pass**. Falsifiers are reported so that non-vacuity
can be judged: E01 breaks the floor bound in 109/200 cases when a zero-weight
edge is admitted; E06 finds 0/300 verdict changes under provenance
relabelling against 160/300 under resolution perturbation.

Two are **negative controls**, in which failure of the method is the expected
and confirmed result:

| | |
|---|---|
| **E21** | The instance-specific composition test returns `r = 1.0`, `RMSE = 6.8e-17` on 2,000 cascades generated by a process that violates the composition law by construction. The test cannot fail, so it has no null. |
| **E22** | A binding with `eta = 0.002` yields predictions constant at fixed cascade length; no comparison among composition rules separates them. |

E23 shows the corrected test does have a null (`r = 0.996` conforming vs.
`0.338` violating). Applied to the Zürich record typed by decade it returns
`eta = 0.0013` — near zero, meaning *that typing* has no discriminating
power. Reported as found rather than replaced with a typing chosen to
succeed.

## Status

The manuscript is self-contained: every object is a finite weighted graph or
a construction on one, and only externally published literature is cited.
Empirical adequacy — whether these agents model human deliberation — is
explicitly **not** claimed (§15); establishing or refuting it would leave
every theorem intact.
