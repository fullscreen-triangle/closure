# Code of Conduct

## The short version

Be decent. Argue with the work, not the person.

## Scope

This applies to issues, pull requests, discussions, and any space where you
are representing the project.

## Expected

- Assume good faith, including when you think someone is wrong.
- Criticise ideas, code, and claims. Not people.
- Accept that a well-argued disagreement may not be resolved, and say so
  rather than escalating.

## Not acceptable

Harassment, personal attacks, demeaning comments, publishing others' private
information, and sustained disruption of discussion.

## Enforcement

Report to **kundai.sachikonye@tum.de**. Reports are handled privately.
Responses range from a warning to a permanent ban, proportionate to the
conduct and to whether it repeats.

## A note specific to this project

Much of this repository consists of arguing that certain features cannot
exist. Disagreement about that is welcome and is the most useful kind of
contribution — but make it as an argument against the theorem, with reasons.
"This is obviously wrong" is not a contribution.
